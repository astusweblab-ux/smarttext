# Политика конфиденциальности SmartText

**SmartText** — локальный AI-ассистент для работы с текстом.

## Какие данные собирает расширение

SmartText **не собирает и не передаёт** персональные данные на внешние серверы. Вся обработка данных происходит локально на устройстве пользователя.

### Данные, которые хранятся локально:

- **Настройки пользователя**: выбранная модель AI, температура, настройки интерфейса, выбранные кнопки панели.
- **История действий**: исходный текст и результаты обработки (сохраняется только по желанию пользователя).
- **Статистика использования**: количество использований каждого действия.

Все эти данные хранятся исключительно на устройстве пользователя через `chrome.storage.local`. Пользователь может в любой момент очистить историю в настройках расширения.

### Данные, которые обрабатываются:

- **Выделенный текст**: текст, который пользователь явно выбрал для обработки.
- **Загруженные файлы**: содержимое файлов (TXT, MD, DOCX, PDF), которые пользователь явно выбрал для обработки.
- **Голосовой ввод**: распознанная речь (обработка происходит локально, запись не сохраняется).

## Как используются данные

- Все операции AI выполняются локально через Chrome Built-in AI API или transformers.js.
- Данные не покидают устройство пользователя.
- Данные не передаются третьим лицам.
- Данные не используются для таргетинга рекламы.

## Синхронизация (опционально)

При включённой опции "Синхронизация истории" настройки и история могут синхронизироваться между устройствами пользователя через `chrome.storage.sync`. Это использует стандартный механизм синхронизации Chrome и подчиняется политике конфиденциальности Google.

## Ваши права

Вы можете в любой момент:
- Очистить историю действий
- Сбросить настройки
- Отключить синхронизацию
- Удалить расширение
